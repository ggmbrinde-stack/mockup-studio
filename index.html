Welcome to Mockup Studio

Mockup Studio turns selected artwork into a real vector SVG with vectorizer.ai, then places it over the original on a “Vectorizer” layer. A quick setup, about a minute.

Language
  1. Select artwork and click “Vectorize selection”.
  2. Sign in once to vectorizer.ai; the session is kept for later runs.
  3. Select several objects to vectorize them one by one.
Sign in to vectorizer.ai

A normal Chrome window opens. Sign in there, then close it. The session stays in Documents/VectorizerBridge, so this is only needed once.

Defaults

These can be changed at any time in Settings.
