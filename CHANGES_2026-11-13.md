# Changes — 2026-11-13

Covers the panel work shipped in **2.3.13 → 2.3.24**. `CHANGELOG.md` still ends at 2.3.10; this
note is the record of what happened after it.

---

## 1. The app is called Mockup Studio

Every visible string said "Vectorizer Bridge" while the product is named Mockup Studio.

**Changed:** window title, panel header, welcome copy (EN + PT), both Extensions menu entries
(`Mockup Studio`, `Mockup Studio (floating)`), installer/uninstaller console text, and the
"Window > Extensions > …" instructions.

**Deliberately unchanged** so an update lands over an existing install and keeps its settings:
extension id `com.bestofgifts.vectorizerbridge`, the `Documents\VectorizerBridge` runtime folder,
the `VB` namespace, and every file/folder name. The "Vectorizer" *layer* and the vectorizer.ai
service keep their names — they are not the app.

---

## 2. Full State and Mini State

One DOM, two states on `.app` (`mode-full` / `mode-mini`, plus `data-mode` on `.app`, `<body>` and
`<html>`), decided in one place by `js/core/app.js`. No duplicated markup, every id handler shared.

- **Full State:** header, live status, selection line, primary button, hint, actions, Settings
  accordion, History, Log, Updates, footer.
- **Mini State** (`?view=window`): header with a 26×26 boxed ✕, status, primary button,
  "Compact Window Mode" caption. No sections that need a full dock.

**Design values now come from `design/NOTES-v1.md`**, not from estimates: Inter with a Segoe UI
fallback, 16 px app inset, 10 px between sections, 6 px cards with 10 px padding on a soft border,
38 px primary button with 6 px corners and a 13 px label.

---

## 3. Statuses

- Full State reads a sentence ("Ready to vectorize", "Placed successfully", "Sign in required");
  the mini window reads a word ("Ready", "Done", "Sign in").
- Colour carries the state: accent, success, danger, warning.
- **Every** status has a short form in mini, not just the five in the spec. Statuses arrive
  already translated, so the text is mapped back to its key to swap in the short form — that also
  covers calls that append detail ("Error: connection failed" → **Error**).
- Live batch progress keeps its counter ("Batch 1/3"), unknown text is clipped with an ellipsis,
  and the Log still records the full sentence.
- Switching state repaints the current status and the selection line ("3 layers selected —
  Artwork.ai" in full, "3 layers selected" in mini).

## 4. Bugs fixed

| Bug | Symptom | Fix |
|---|---|---|
| Mini actions row hidden | No Cancel (or Sign in / folders) in the floating window during a run | `body.canCancel` set from `updateButtons()`; CSS returns the row with only Cancel |
| Footer version | Printed `Illustrator 29.x` from `app.version` | Shows `Mockup Studio v<version>`, read from `CSXS/manifest.xml` |
| Close button | `window.close()` is a no-op in a CEP panel | Falls back to `CSInterface.closeExtension()` |
| Swallowed startup error | `refreshStatusCopy()` read `state` before it was assigned; the throw vanished into `catch (e) {}` | Guarded with `state && state.selection` |
| Dead CSS | Rules kept matching markup that no longer existed | Removed; new check prevents recurrence |
| Duplicate repo URL | Releases link hardcoded while the updater had its own `DEFAULT_REPO` | One `updateRepo` in `js/admin-config.js`, read by both |

## 5. Verification tooling

- **`tools/verify-css.cjs`** — fails when a CSS id or class no longer matches anything in
  `index.html` or in any string literal in the project. Catches rules that outlive their markup.
- **`tools/verify-all.cjs`** — one command for everything: panel wiring, agent helpers, export
  options, dead CSS, and `node --check` over every JS file. Fails if any of them fails;
  `--verbose` shows full output.

```
$ node tools/verify-all.cjs
  ok   panel wiring
  ok   agent helpers
  ok   export options
  ok   dead CSS
  ok   js syntax (23 files)

All checks passed (5 checks).
```
